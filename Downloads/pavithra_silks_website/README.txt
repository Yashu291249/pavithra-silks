PAVITHRA SILKS WEBSITE
=====================

Files:
- index.html: complete responsive website
- assets/: illustrative banner, collection and product photos

QUICK START
1. Extract pavithra_silks_website.zip.
2. Open index.html in a browser to preview it.
3. Before sharing the site, edit index.html:
   - Search for SHOP_WHATSAPP and replace 91XXXXXXXXXX with your real WhatsApp number including India country code, digits only (example format: 919876543210).
   - Update demo product names, prices, fabric, color and product codes in the `products` array.
   - Replace the illustrative photos in assets/ with your own photos, keeping the filenames the same, or update the image paths in the products array.
   - Update shipping, address, contact and return-policy details to match your real shop.
4. Test the WhatsApp buttons and all sections.

FREE HOSTING OPTIONS
- Netlify Drop: https://app.netlify.com/drop
  Sign in if prompted, then drag the extracted website folder (containing index.html and assets/) onto the drop area.
- GitHub Pages: https://pages.github.com/
  Create a repository, upload index.html and the assets folder, then enable Pages in repository settings.

NOTES
- No paid domain is required; free hosting gives you a provider subdomain.
- This is a static front-end site. Product data is currently stored in index.html; there is no secure admin login, live inventory database, or online payment checkout.
- Product imagery and prices are illustrative placeholders. Replace them with your real inventory before advertising or accepting orders.
